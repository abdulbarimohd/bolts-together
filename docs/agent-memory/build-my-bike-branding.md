**Superseded as of 2026-08-18.** New work follows the blueprint palette in
[[bolts-together-rebuild]] — dark only, ink `#0A0C10` with safety-orange
`#FF5D2E`. Don't apply the gold/brown system below to the rebuild.

**Legacy identity**, still live on `build-my-bike.vercel.app` and applying only to
that existing site: gold `#b45309` (`chassis`) and brown `#78350f` (`contact`),
deliberately not purple (too close to PCPartPicker). Dark treatment on the top nav
ribbon only; category badge backgrounds stay neutral silver/grey with just the
text in gold/brown; never collapse `chassis` and `contact` into one colour.

**Why this is worth remembering even though it's superseded:** the gold took
several rounds to land — early attempts read as rust rather than a true
yellow-gold, and two competing accents had to be unified into one. If the new
blueprint palette is ever revisited, that history is the reason the user is
sensitive to accent colours drifting warm.
